# Codestra CRM Call Follow-up UX

Optional Odoo 19 UX addon for the core `codestra_crm_call_followup` module.

## Features

- agent snooze buttons for 5, 15, or 30 minutes;
- one-minute cron release with an Odoo bus notification;
- contextual primary actions for email, scheduling, or simple completion;
- direct CRM and customer shortcuts from the post-call dialog;
- same-session popup reconciliation after close, reconnect, or temporary failure;
- responsive desktop and narrow-screen layout;
- manager visibility into snooze history.

This addon does not add telephony writes, public controllers, credentials, or a
new provider integration.
