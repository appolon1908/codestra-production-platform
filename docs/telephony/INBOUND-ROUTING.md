# Inbound routing

Inbound DIDs, groups, IVRs, languages, business/after-hours, holiday, queue,
supervisor, voicemail and emergency fallbacks remain tenant/campaign
configuration. The base menu contract supports Sales (1), Support (2), Billing
(3), and Spanish (9), but no production DID or menu was changed.

Section 2 lab routing uses only the isolated 6101 endpoint and local echo
application. Any final tenant routing requires middleware approval and a
disabled-first reconciliation plan.
